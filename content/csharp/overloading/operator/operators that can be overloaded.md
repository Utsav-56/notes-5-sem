
These operators can be overloaded for user-defined classes and structs.

| Category                              | Operators                                           |
| ------------------------------------- | --------------------------------------------------- |
| **Binary Operators**                  | `+`, `-`, `*`, `/`, `%`, `&`, `\|`, `^`, `<<`, `>>` |
| **Unary Operators**                   | `+`, `-`, `!`, `~`, `++`, `--`, `true`, `false`     |
| **Relational (Comparison) Operators** | `==`, `!=`, `>`, `<`, `>=`, `<=`                    |
